## What I do

I work where enterprise RPA meets modern AI engineering: UiPath, Automation Anywhere A360, Power Automate, LangChain, RAG pipelines, and MCP servers, wrapped around real business workflows.

|  |  |
|---|---|
| **AI + RPA** | LLM-powered workflows on top of UiPath, A360, and Power Automate |
| **MCP servers** | Agent-facing tools for Orchestrator, Control Room, queues, jobs, and bots |
| **Full-stack** | Spring Boot, FastAPI, React, React Native, Kafka, Docker, cloud-ready services |
| **Developer tools** | Script managers, browser extensions, diagnostics, internal productivity platforms |

**Currently:** building MCP tooling for RPA ecosystems, designing agentic automation with human-in-the-loop exception handling, and connecting LLMs to enterprise platforms through secure APIs.

## Impact at Xalta

**Enterprise Automation & AI Integration Developer** · Feb 2024 – present

- Built an LLM-powered email and timesheet system with LangChain, ChromaDB, and PyQt5 that drafts status emails from historical vector context.
- Architected healthcare payer-credentialing automation on A360, AARI+, and UiAgents, with human-in-the-loop exception handling.
- Automated EOB file generation for U.S. hospital invoices by integrating Meditech healthcare APIs with Python, C#, and A360.
- Delivered invoice automation for client brightFin as a core developer, using UiPath Document Understanding and Orchestrator queues.
- Designed a multi-provider LLM layer (OpenAI, Gemini, Claude) for UiPath-to-A360 migration tooling, with RAG-based bot config generation.
